For Bedrock players coming in through Geyser: the Sell Wand as a custom item. Zip `pack/` into Geyser's `packs/`
(e.g. `rainseconomy.mcpack`) and copy `custom_mappings/rainseconomy.json` into its `custom_mappings/`, then restart
Geyser (needs `enable-custom-content: true`). Placed Auto Sell Chests look like plain chests on Bedrock — it has no
display entities — and work the same.
